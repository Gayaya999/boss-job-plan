# 生成排版简历文件

简历内容按第 4 步的方案写好（取舍、顺序、文案都已对应 JD），本文件负责把它变成**能直接投递的文件**。

## 一、流程

1. 把最终简历内容写成 `简历_<姓名>_<岗位>.json`（格式见下），保存在工作目录。
2. 运行：
   ```bash
   python3 <本 skill 目录>/scripts/make_resume.py 简历_<姓名>_<岗位>.json <工作目录> --open
   ```
   会生成三个文件：
   - `.pdf`：投递用，A4，由本机 Chrome 或 Edge 导出；
   - `.html`：预览用，占位符黄色高亮，顶部有草稿提醒；
   - `.md`：可编辑版，方便复制进 Word、飞书或其他简历平台。
3. 读取输出最后一行的 JSON 摘要，然后检查：
   - `pages` 超过 `max_pages`（默认 1）时，**先删内容，再调排版**：压缩弱相关经历、合并相近条目、每段最多 3–4 条要点；还超出再设 `"density": "compact"`。改完重新生成。
   - `placeholders` 非空时，文件名会自动带“_草稿”。告诉用户还差哪些信息，可以用问卷收集；**不要用猜测的内容填占位符**。
   - 有条件时，查看 PDF 渲染效果：用浏览器打开 HTML 截图，或直接读取 PDF。重点看是否截断、对齐和分页。
4. 用户要 Word 时，可以用 docx 相关技能，根据同一份 JSON 或 Markdown 生成。

## 二、JSON 格式

```json
{
  "name": "张三",
  "target": "求职意向：AI 产品实习生｜深圳｜每周 5 天，可实习 3 个月以上",
  "contacts": [
    "138-0000-0000",
    "name@example.com",
    {"label": "作品集", "value": "https://example.com"},
    {"label": "GitHub", "value": "https://github.com/xxx"}
  ],
  "summary": "（可选）一句话个人定位，多数情况不写，留给项目说话",
  "accent": "#0f7b6c",
  "density": "normal",
  "max_pages": 1,
  "photo": "（可选）照片路径",
  "file_name": "简历_张三_AI产品实习生",
  "sections": [
    {"title": "获奖经历", "type": "list", "items": [
      {"text": "XX 黑客松 XX 赛道 **金奖**（作品：XX）", "date": "2025.07"}
    ]},
    {"title": "项目经历", "type": "entries", "items": [
      {"title": "XX：AI 设计助手", "role": "个人独立项目", "date": "2026.03 – 2026.06",
       "link": "https://…",
       "bullets": ["从身边店主的真实需求出发……", "独立完成……"]}
    ]},
    {"title": "教育背景", "type": "entries", "items": [
      {"title": "XX 大学", "role": "产品设计 本科", "date": "2024.09 – 2028.06（预计）", "bullets": ["相关课程：……"]}
    ]},
    {"title": "专业技能", "type": "skills", "items": [
      {"label": "AI 编程", "text": "Claude Code、Cursor……"}
    ]}
  ]
}
```

- `type` 有四种：
  - `entries`：经历条目，包括标题、角色、时间、链接和要点；
  - `list`：单行列表，适合奖项、证书，右侧可写日期；
  - `skills`：“标签：内容”两列；
  - `text`：纯段落。
- 文本中可以用 `**加粗**` 突出关键结果或关键词，每条最多一处，否则会失去重点。
- 未确认的信息一律写成 `【说明】`。脚本会统计并高亮这些占位符，有占位符时文件名带“_草稿”，提醒用户补完才能投递。
- `accent` 是主题色，默认墨绿。可以按行业微调，比如科技公司用蓝或绿，设计类可以更鲜明，但不要用荧光色。

## 三、版面规则

- 校招和实习简历默认 1 页，社招最多 2 页。顺序按第 4 步的结论排，**与目标岗位最相关、分量最重的栏目放最前**。
- 每段经历 2–4 条要点，每条最多两行，动词开头，写清楚做了什么、怎么做的、结果如何。
- 联系方式、作品链接放在页首右侧，作品类岗位的作品集链接必须放进去。
- 照片按用户在问卷里的选择决定，没选就不放。
- 不写“自我评价”这类空话，除非 JD 特别要求。
